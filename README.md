## 📖 О проекте

**Desktop Abyss: Taskbar Chronicle** — настольная Idle RPG с готическим оформлением, выполненная в форм-факторе компактного виджета (540×168 px), закрепляемого над панелью задач Windows. Отряд героев непрерывно сражается в глубинах Бездны, отражая волны нежити и боссов, пока игрок занимается своими делами.

### Ключевые особенности:
- 🏰 **Компактный боевой виджет**: работает в фоне прямо над таскбаром, поддерживает режим поверх всех окон (Pin `◆`) и единый выкатной ящик (`PanelDrawer`) для интерфейсных панелей.
- 👥 **6 классов героев**: Рыцарь, Ассасин, Пиромант, Рейнджер, Некромант, Паладин с тактическим построением (авангард, фланг, стрелки, глубокий тыл).
- 📊 **43 детальные характеристики (Detailed Stats)**: Attack (21), Defense (12), Utility (10) — формулы скорости атаки, кулдаунов (CDR), блока (поглощение 60%), уклонения, вампиризма, регенерации HP, стихий и резистов (Огонь, Холод, Молния, Хаос).
- 🌄 **4 процедурных многослойных биома**:
  - *Катакомбы Падших (Crypts)*: готические арки, надгробия, цепи, чаши с загробным огнем, стелющийся туман.
  - *Оскверненная Чаща (Forest)*: вековые узловатые деревья, бирюзовые грибы, светящиеся споры.
  - *Пепельная Кальдера (Caldera)*: обсидиановые скалы, реки магмы, поднимающиеся искры и пепел.
  - *Цитадель Бездны (Citadel)*: витражи с эфирным светом, парящие обелиски, светящиеся рунические круги.
- ✨ **Боевые спецэффекты в реальном времени**: баллистические стрелы, огненные шары пироманта, костяные копья некроманта, световые столбы паладина, слэш-следы взмахов клинков, искры критов и рунические щиты при блоке.
- 🛡️ **Сияющий рунический купол**: многослойный энергетический барьер с пульсацией, рунами (`ᚨ ᚱ ᛟ`) и вспышками поглощения урона.
- 💎 **Богатый лут и ролевая логика**:
  - 40 архетипов экипировки (эспадоны, фальшионы, стилеты, косы, гримуары, башенные щиты, мантии, латы).
  - 48 актовых аффиксов с грамматическим согласованием родов.
  - Взрыв лута: при гибели элитников и боссов вылетают сияющие сферы лута цвета редкости (Common → Mythic) с плашками дропа.
- ⏳ **Истинный оффлайн-прогресс**: математический расчет волн, золота и опыта при закрытой игре (2–12 часов) с защитой от накрутки системного времени.
- 🌌 **Древо Рун (Runes Constellation Web)**: паутина созвездий из 151 узла с великими рунами (Keystones).
- 🔮 **Куб Синтеза (Horadric Cube)**: трансмутация и крафт экипировки.

## 🚀 Установка и запуск

### Требования
- Python 3.10 или выше
- Windows 10/11 (или Linux/macOS с установленным X11/Wayland)

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск игры
```bash
python main.py
```

### Запуск автотестов
```bash
python -m unittest discover -s tests -v
```
*(Все 100 автотестов проходят со 100% успехом)*
